# Prompt → 飞书多维表格

把用户提供的 prompt 素材（**图片截图** 或 **长文本**，或两者）转成干净的结构化记录，
写入飞书多维表格。底层通过本仓库的 `feishu_cli.py` 调用飞书 OpenAPI。

## 工作流程

1. **识别与抽取。** 读取用户给的截图/文本，产出以下逻辑字段（缺失就留空、不要编造）：
   - `标题`：一句话概括这个 prompt 的用途（简短，如“苹果广告电影感镜头”）。
   - `分类`：若能判断则给一个短标签（如“镜头”“风格”“修图”）；不确定就留空。
   - `提示词-英文` / `提示词-中文`：把 prompt 原文**一字不改**放进对应语言字段。
     **默认不优化、不扩写、不润色。** 只有一种语言时，另一字段默认留空；仅当用户
     明确要求翻译时才补，且须忠实翻译、不改写创意内容。用户明确说"优化 prompt"才可改。
   - `评分`：只有当用户明确给出评分时才填数字，否则留空。
   - `备注`：用户的额外说明、来源平台、注意事项等。
   - `链接`：素材里出现的原始链接（X/Twitter、YouTube、Instagram 等）。
   剔除 UI 界面文字、水印、无关内容，只保留真正的 prompt 与元信息。

2. **附件（可选）。** 如果用户提供的这张图**本身是想保存的参考图**，把它保存到本地
   （如 `scratch/ref1.png`），稍后用 `--media 相关图片=scratch/ref1.png` 上传。
   纯粹是“prompt 截图”而非参考图时，不要作为附件上传。

3. **先确认。** 把抽取出的字段简明列给用户核对（尤其是标题、分类、评分），
   等用户确认或修改后再写入。

4. **写入。** 调用 CLI：
   ```bash
   python feishu_cli.py add-record --data '{"标题":"...","分类":"镜头","提示词-英文":"...","提示词-中文":"...","备注":"...","链接":"https://..."}'
   ```
   如需附件：追加 `--media 相关图片=scratch/ref1.png`（视频用 `--media 相关视频=xxx.mp4`）。
   不确定字段结构时，可先加 `--dry-run` 查看映射结果，确认无误再正式写。

5. **回报。** 输出创建成功的 `record_id`，并告知已写入哪些字段。

## 注意
- 字段名必须与 `config/field_map.json` 的逻辑名一致（`标题/分类/提示词-英文/...`）；
  实际列名由该文件映射，若用户改过表结构，先 `python feishu_cli.py list-fields` 核对。
- 首次使用前需在 `.env` 配好飞书凭据与 `app_token/table_id`（见 `docs/SETUP_FEISHU.md`）。
- `分类` 是单选字段：写入的值应是表中已存在的选项名；不确定时先留空或询问用户。
